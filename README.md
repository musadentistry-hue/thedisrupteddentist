# The Disrupted Dentist

Official launch website for *The Disrupted Dentist*, a manifesto by Mauricio Schneider, DDS, MS, on the end of repair-based dentistry and the rise of a profession built on prediction, prevention, preservation and optimization.

**Live:** https://thedisrupteddentist.com

Static site: `index.html` + `cover.webp`. Deployed on Vercel (framework preset: Other, no build step).
